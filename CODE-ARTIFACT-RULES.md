# Code artifact rules

`README.md` explains the lesson. `WORK.md` lists the problems, files to edit, and checks. Files marked `STUDENT TASK` or `STUDENT PROBLEM` are unfinished learner work. `demo_*` files are completed examples; `pattern_*` files are incomplete reference patterns. `challenge.*` is a separate, harder task and must differ in behavior or constraints, not just wording. `*_test.go` and `check_*.py` are executable checks; skipped tests are not checks.

Selected lessons include reference examples under `code/reference/`; these are study material to open after attempting the problem. Official large course labs are linked from the relevant lesson and their original test harnesses remain in their upstream repositories.
