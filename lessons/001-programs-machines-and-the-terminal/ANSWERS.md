# Lesson 001 - Answer key

Try the questions in `WORK.md` before opening this file.

1. Ten bytes: `a` uses 1 byte, e-acute uses 2, the euro sign uses 3, and the grinning-face emoji uses 4 in UTF-8.
2. `66`, because `17 + 5 = 22` and `22 * 3 = 66`.
3. Exit status `0` means success. In PowerShell, inspect `$LASTEXITCODE` immediately after running the program.

Expected example outputs:

- `hello.c`: `Hello, world!`
- `greet.c`: `Hello, Ada!`
- `report.c`: two lines, `Name: Ada` and `Score: 42`
- `arith.c`: `66`
- completed `exercise.c`: `Hello, DART!`
