# FSEGS LIG — Algorithmique et structures de données 2

**Semester:** S2  
**Attached engineering lesson:** 036 — Core Algorithms in Go

## Scope

Advanced linear structures; recursion; stacks/queues; linked structures; trees; binary search trees; hashing; graph representations; traversal; shortest-path intuition; sorting/search complexity; recurrence basics; dynamic programming patterns; algorithm selection and proof.

## Teaching sequence

1. Recursion and recursive specifications.
2. Linked lists, stacks and queues.
3. Trees and traversals.
4. Search trees and balancing intuition.
5. Hash tables and collisions.
6. Graphs, adjacency lists/matrices, BFS and DFS.
7. Divide-and-conquer and recurrence reasoning.
8. Greedy versus dynamic programming at first-year level.

## Exercises

1. Reverse a linked list and state the invariant.
2. Implement a stack and queue with a chosen representation.
3. Write recursive factorial, power, sum, and binary-search functions and trace calls.
4. Traverse a binary tree in preorder/inorder/postorder.
5. Insert/search in a binary search tree and identify worst-case degeneration.
6. Build a hash table with one collision strategy and analyse a collision sequence.
7. Build graph representations and perform BFS/DFS by hand.
8. Find connected components in a small graph.
9. Compare iterative and recursive versions of the same algorithm.
10. Solve one small dynamic-programming problem after first writing the naive recursive formulation.

## Exam patterns

Structure operations, pointer/reference reasoning, recursive traces, tree traversal, graph traversal, hash collision steps, complexity comparison, recurrence intuition, algorithm choice.

## Mastery gate

Solve a linked-list task, tree task, graph task, and recursive task from blank. Explain representation choice and complexity.
