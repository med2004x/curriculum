# LIG S2 practice code

These files are arithmetic and implementation checkers for the subject packs, not answer keys. Complete the written derivation or specification first.

Run the semester suite from the repository root with `python tools/run_lig_tests.py s2`. The suite uses Python's standard-library `unittest`; no package installation is required. Tests for unfinished student functions intentionally fail until you implement them. A passing suite covers only its listed contracts and does not replace the written exercises or semester mastery paper.

Each `test_*.py` states observable behavior, including ordinary inputs and selected boundary cases. Add tests when you encounter new edge cases in your course work. Keep your own derivations and corrections in your portfolio; do not edit expected results just to make a test pass.
