## Recommended study rhythm

1. Retrieve the prerequisite idea from S1 before starting each S2 topic.
2. Write definitions and mathematical steps before using the code workspaces.
3. Mix formal exercises with engineering applications, but do not treat code output as a proof.
4. Keep first attempts, corrected attempts, and an error log for the final mastery check.

This is a suggested self-study rhythm. It does not specify official grades, credits, or exam weighting.

## Practice tests

Run `python tools/run_lig_tests.py s2` from the repository root. Tests for unfinished exercises are expected to fail until you implement the functions in `code/`; a passing test suite does not replace the written course exercises.
