## Recommended study rhythm

1. Study two or three subject packs in parallel: one formal/problem-solving subject, one engineering subject, and one communication/business subject.
2. For each topic, solve by hand before using its Python/SQL checker.
3. Keep first attempts, corrected attempts, and a short error log.
4. Use the final mastery check only after all applicable course packs have been attempted.

This is a suggested self-study rhythm. It does not specify official grades, credits, or exam weighting.

## Practice tests

Run `python tools/run_lig_tests.py s1` from the repository root. Tests for unfinished exercises are expected to fail until you implement the functions in `code/`; a passing test suite does not replace the written course exercises.
