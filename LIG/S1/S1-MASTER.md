# FSEGS LIG — S1 Mastery Checkpoint

Use this packet only after finishing the relevant S1 lessons and academic packs. It is a closed-book rehearsal. No solutions are stored here.

## Part A — Algorithmique / ADS1

1. Write pseudocode for a filtered array aggregation problem.
2. Trace a loop with a non-trivial boundary condition.
3. Implement linear search and one basic sorting algorithm.
4. State a loop invariant and argue termination.

## Part B — Systèmes 1

1. Decode a permission string and answer three access questions.
2. Draw a process tree and explain parent/child states.
3. Explain a pipe and file-descriptor flow.
4. Classify four concurrency scenarios.

## Part C — Mathématiques 1

### Analyse
Perform one domain/limit/derivative/variation exercise and one optimisation problem.

### Statistiques et probabilité
Complete a descriptive-statistics table and solve one conditional-probability problem.

## Part D — Gestion 1

### Comptabilité
Record a fresh transaction sequence, post it, balance it, and derive basic statements.

### Principes de gestion
Analyse a case with an objective, causes, alternatives, decision criteria, and KPIs.

## Part E — Digital / Communication

1. Produce a clean spreadsheet from raw data.
2. Write a professional English email and a 150-word technical summary.

## Part F — Database / Multimedia

1. Model a three-entity database and write five SQL queries.
2. Solve image/audio/video storage calculations with units.

## S1 pass rule

Treat this like a real exam. No notes, no copied code, no answer lookup. Record time used, mark every missed item, classify the cause of failure, and repair it later with changed data.
